# Scam Radar app (Flutter)

Android, iOS and Web app for Scam Radar. Guide for developers: `docs/pdf/guide_adiya.pdf`.

```bash
flutter pub get
```

```bash
flutter run -d chrome --web-port 8091 --dart-define-from-file=env/local.json
```

```bash
flutter analyze && flutter test
```

Screens and their tests are listed in `../docs/SCREENS.md`.
