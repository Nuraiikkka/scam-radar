# Аудит источников и первый эксперимент — 16 октября 2026

## Проверенные источники

1. [OptiScam / Multimodal Filipino Scam Video Dataset](https://www.kaggle.com/datasets/julesgregoryagustin/training-filipino-scam-dataset),
   автор Jules Gregory Agustin, версия 6. Публичный API Kaggle указывает
   60 897 094 320 байт и лицензию CC BY-NC-SA 4.0. Карточка описывает 2 000
   роликов с балансом scam/legitimate и темы crypto, ewallet, giftcard,
   giveaway, p2e, task. Это заявленный состав всего набора, а не количество
   скачанных нами записей. Метки частично автоматические, покрытие речи неполное.
   Исходная карточка сохранена локально в data/raw/optiscam/dataset_metadata.json.
2. [Производные OptiScam shards](https://huggingface.co/datasets/TamAko783/filipino-scam-final-shards).
   Опубликованы pickle-файлы с кадрами и обучающими диалогами. Мы их не скачивали
   и не исполняли. Для лёгкого эксперимента исходные JSON удобнее.
3. [VidScam / Detecting YouTube Scam Videos via Multimodal Signals and Policy Reasoning](https://arxiv.org/abs/2509.23418).
   Релевантное исследование YouTube-схем с денежными обещаниями, розыгрышами и
   криптовалютами. Во время этого аудита готовый независимый набор файлов с
   подтверждённой лицензией не получен. Данные исследования здесь не использованы.
4. [Investment-related deceptive content, Mendeley](https://data.mendeley.com/datasets/6wnd7jrt6z/2).
   Тексты/метаданные из разных источников, а не видеодатасет. Авторы отдельно
   предупреждают, что метки не равнозначны подтверждённым инвестиционным скамам.
   В обучение не включён.

## Что фактически собрано

Доступны манифесты crypto и giftcard. Для ewallet, giveaway, p2e и task
проверенные адреса манифестов возвращают 404; это не доказывает отсутствие
данных в полном архиве. Выбрано по 50 записей на класс каждой доступной темы,
rank <= 1. Из 200 запросов 38 записей недоступны; получено **162 JSON**:

| Тема | Scam | Legitimate |
| --- | ---: | ---: |
| crypto | 48 | 50 |
| giftcard | 50 | 14 |
| Итого | 98 | 64 |

Это производные реальных видео: речь и OCR. Сами видео и кадры не скачаны.
Некоторые файлы из манифестов отсутствуют; полный список ошибок сохранён
в collection.json. Сбор поэтому не является сбалансированной или случайной
выборкой всех роликов TikTok. Разметка не проверена нами вручную.

## Методика и результат

Бинарная LogisticRegression на word/character TF-IDF, CPU. В признаки идут
только речь и OCR. Категории источника не преобразовывались автоматически
в пять категорий задания: такое соответствие требует проверки содержания.

Разбиение: **97 train / 32 validation / 33 test**. Группы одинаковых ID и
точных/близких текстов не пересекаются между частями. Авторские ID отсутствуют:
утечку между роликами одного автора или визуальными копиями исключить нельзя.
Один пример, прочитанный при аудите источника, не допускается в validation/test
вместе со своей группой. Словари обучались только на train; C и порог выбирались
по validation. Test не использовался для настройки.

| Метрика на тех же 33 тестовых записях | Обученная модель | Текущие правила |
| --- | ---: | ---: |
| Accuracy | 81.8% | 45.5% |
| Macro-F1 | 0.785 | 0.450 |
| Precision класса scam | 87.0% | 85.7% |
| Recall класса scam | 87.0% | 26.1% |
| Пропуски scam из 23 | 3 | 17 |
| Ложные срабатывания из 10 legitimate | 3 | 1 |

Для сравнения правила сведены к бинарному прогнозу: category != none.
Модель обнаруживает больше примеров с меткой scam, но чаще ошибается на
legitimate. **Три ложных срабатывания из десяти — существенная проблема.**
Это предварительное согласие с метками источника на маленьком тесте, а не
доказательство точности 81.8% на новых TikTok-видео. Оценки не калиброваны.
Русский/казахский язык, пять категорий, видео без текста, ошибки ASR/OCR и
сквозная обработка видео в этом эксперименте не оценивались.

На момент проведения эксперимента модель не была включена в API. Позже она
подключена по запросу пользователя как явно экспериментальный бинарный прогноз.
Для подтверждения её качества нужен расширенный человеческий контрольный
набор и проверка допустимого уровня ложных срабатываний.
Полные метрики, хеш данных, версия sklearn, состав разбиения и прогнозы лежат
в baseline_metrics.json, split_manifest.jsonl и test_predictions.jsonl.
