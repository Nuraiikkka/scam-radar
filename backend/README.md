# Backend (Nuray)

Что здесь:

- `text_classifier.py` - ищет слова мошенников в тексте и определяет категорию
- `fusion.py` - считает итоговый риск от 0 до 1
- `evaluate_texts.py` - проверяет, что всё работает

Как запустить:

```
cd backend
python scripts/evaluate_texts.py
```

Должно быть: `Правильно: 14 из 14`

Как это работает:

- 1 найденное слово = 0.3 риска
- риск меньше 0.3 = мошенничества нет
